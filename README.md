
# SeleniumRobot recorder
Cette extension est fortement inspirée de SeleniumBase Recorder.
Le projet original a été réalisé par Michael Mintz.
Cette version est une adaptation et évolution pour le plugin SeleniumRobot Recorder développé par Covéa.
Limits: 
- Only one server can be started at the same time among all intelliJ instances


1.Installation du recorder manuellement

-Ouvrir Chrome
-Allez dans :
chrome://extensions
-Activez le Mode développeur (en haut à droite)
-Cliquez sur Load unpacked
-Sélectionnez le dossier recorder-extension

L’extension est maintenant installée.

2. Installation du plugin dans IntelliJ

Ouvrez IntelliJ
Allez dans :
File → Settings… → Plugins
Cliquez en haut à droite sur la roue crantée ⚙
Sélectionnez Install Plugin from Disk…
Choisissez le fichier ZIP :
seleniumrobot-recorder-<version>.zip
Cliquez sur OK
Redémarrez IntelliJ lorsque cela est demandé

Le plugin est maintenant installé.
